# Skills

This directory is the canonical direct mail skill pack. Each subdirectory
contains a `SKILL.md` entrypoint for one direct mail workflow.

Current skill lanes:

- `dm-plan`
- `dm-create`
- `dm-execute`
- `dm-measure`
- `dm-strategist`

When changing skills, keep the root `README.md` and the public site in sync.
The repo-local `.agents/skills` path points here so Codex, Claude, and other
agents all use the same skill definitions.
